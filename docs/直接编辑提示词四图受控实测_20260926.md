# 直接编辑提示词四图受控实测

日期：2026-09-26。用户批准上一轮提出的下一步四图测试。

## 结论

**完整 C 合同和直接编辑合同都保留了本轮检查的主要床架结构，直接编辑短合同没有显示可重复的优势。本轮不替换生产提示词，也不扩大测试。**

四张图床尾均为 11 根细栏杆；同侧固定入口、连续侧梁、房子形床头、屋顶饰条、烟囱及壁龛主要关系保留。未复现此前少一根栏杆、入口立柱外贴延长及新增下部外露螺钉的明确错误。

这支持当前调用在这些提示词下能够保留主要产品结构，同时实际更换房间、床品和摆件。不能将此前失败概括为“模型只能重绘、无法保留主体”。但两组各有一张入口局部受新毯子流苏遮挡；精细木纹、饰面是否完全不变尚未确认，不能宣布全面保真通过。

## 4. 对原因判断的影响

1. **不能认定“完整提示词必然导致主体重绘”。** 本轮完整组也保留了预设的主要结构。
2. **不能认定“删除重复说明已经解决”。** 直接组没有在两次输出中相对完整组形成稳定优势。
3. **没有复现旧错误，不等于旧错误不存在。** 之前的少栏杆和入口连接改变仍是有效失败样本；本次主要说明结果存在变化，不能将单个样本推成必然表现。
4. **遮挡是本轮真实的验证限制。** 两份提示词允许换毯子等床品，禁止用摆件掩盖错误，但没有具体限制新床品始终避开每个待检查连接。输出流苏遮挡使部分结构不可判断；并不证明遮挡下面一定发生了结构改变。
5. **上一轮黑白选区失败，不能替代本次原图编辑判断。** 生图模型画出的简化蒙版不能直接保护像素；本次真实照片编辑却能保留主要几何。两类任务不应混为同一个能力结论。

## 5. 处理决定

- 本次四图按预定规模结束。没有再加词重跑、切模型、增加 ASIN、调用 SAM 或接入新的分割流程。
- 保留直接编辑合同为候选；本轮没有证据支持以其替换生产合同，更不能声称所有品类、角色已经修好。
- 后续如要继续，先整理已有成功与失败输出对应的请求条件及能力证据，明确哪些失效已经复现，再决定有区分力的下一项对照。不要继续凭一个词猜原因。
- 若今后调整床品遮挡约束，应在现有规划/编辑边界内处理，且对两组同等应用；它只能解决可检查性，不能冒充纹理或结构保真的根治方案。本轮未执行此修改。
