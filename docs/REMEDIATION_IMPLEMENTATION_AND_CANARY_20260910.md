## 2. 已落地修改

### P0：事实与运行故障

1. 删除对所有单词少于两个的文案直接过滤：Pathway、Wedding 等完整单词可作为真实源图卖点，残缺字符仍不能作为可靠事实。
2. 文案响应缺失完整字段时回到现有完整对象修复，不再误走只修标题分支；删除与四字段响应合同冲突的 evidence 示例键。
3. 联合观察保留请求、失败响应正文、校验错误、长度与结束原因，缺少 sources 数组使用明确错误。原生 Gemini 请求声明 JSON 输出与已有输出 token 预算，排除 thought 部分。
4. HoldAI 当前模型列表仅返回生图模型，未找到所配 Gemini。现有 QA 路由原位替换为已验证能读取图片的 NUWA Gemini，不新增备用验收路径。
5. 实图验证又定位了 QA 提示词的包装歧义：模型返回 `{"schema": {...}}`，而校验要求顶层观察字段。生图停止后，原位改成输入上下文和顶层输出对象两段，并明确坐标顺序。没有加入解包兼容分支，没有放宽失败判定。

### P1：规划职责

- Gemini 继续负责视觉设计，配色工具只提供计算参考。
- 环境配色、光照、陈设、字型、图文组件各归现有字段负责；构图字段要求描述布局而非再造事实、数值、颜色或字稿。
- 保留小型局部标签托底的设计自由，替换大面积胶囊、装饰叶片和叠层容器的默认设计倾向。
- 明确局部源图仍是局部证据，总条数不授权扩展完整产品画面。

实测显示：以上规划指令尚未稳定落实到 Gemini 的每个自由文本输出。这是未解决项，不以指令存在代替行为通过。

### P2：最终 prompt 投射

- size 不再接收整段房间陈设和软装色板，继续继承同 child 的字体和图文组件设计；保留源尺寸图场景类型，不强制全类目改白底。
- func 的参考编辑合同保留源图可见视野与结构关系；移除床架也会接收的镜柜专属说明。
- 没有用字符截断压缩提示词，没有更换成 Pillow 文案排版。

### P3：配色工具

- 删除候选色板中固定 205 度图文字色/引导线色相与固定托底色相，改由候选强调色、墙面色派生。
- 不认识的颜色名称不再作为普通中性色生成假配色，例如 Begonia 返回待视觉确认的颜色依据。
- 计算指标明确标注为起始参考色板指标，不冒充 Gemini 最终设计或实际成图的质量评分。
- registry 明确规划权属于 Gemini，执行权属于图像模型；没有恢复旧固定色板。

### 逐张结论

1. **床架 func_02：不通过人工对照。** 字体和橙褐色图形方向更集中，但源图上方仅显示少量局部板条，产物仍扩展成更大床架视图。新规划的 image_direction 仍写入“8 plywood slats spanning the frame”，与局部证据要求冲突。总条数文案是事实，并不授权把该事实转成更大可见视野。现有自动 QA 给出 pass，未识别这一问题；不能据此宣布无重绘。
2. **床架 size：部分改善，未验收。** 去掉无关房间陈设，图表更简洁；但标题偏大，承重在徽标内外重复出现，尺寸文字和标题颜色也不相同。QA 判定 Dimensions、300、300 lbs 未授权，其中 Dimensions、300 lbs 在源图可见，不能笼统当作模型虚构；无单位 300 则是候选新增的重复表达。当前任务的尺寸事实列表未完整涵盖源图宽度和承重，观察返回额外真实测量时又被视为绑定不完整。需要修现有事实传递/授权判定，不能一律放行或删除源图事实。
3. **浴室柜 func_02：明确结构失败。** 源图一块内层板、两个储物空间，产物两块内层板、三个空间。QA 修复后准确定位同一矛盾并判 fail。衬线字和大胶囊消失，但仍继承源图顶部横带、底部色带和圈图布局，标题与正文颜色也不是同色。只是换了容器外观，不能说设计独立性问题已解决。

### QA 验证分层

- 初次 QA：两张因额外 schema 包装未判定，另一张排队超时；均没有假装通过。
- 停止生图后，仅修改 QA 提示词表达，以单 worker 顺序复验同三张，不生成新图。
- 复验：床架 func_02 pass、size fail；浴室柜 func_02 fail。三张均获得有效模型观察，不再是权限错误或 schema 包装错误。
- 人工与自动结论并不完全一致，尤其是局部视野扩大。自动 QA 的覆盖还不能当作全面结构保真的保证。
- 多 QA 任务争用同一模型槽仍有时限风险，本次串行复验只验证可用性，没有修订生产并发策略或证明批量吞吐。

## 5. 剩余工作与顺序

1. **先完成现有规划职责的实际落实。** 对构图只表达画面组织、对源证据只保留可见产品区域，避免 image_direction 再次生成产品结构描述。浴室柜的细节图同时包含多层调节位置示意，需区分示意位置与实际安装层板；不能靠新增全局“禁止重绘”句子解决。
2. **修现有 size 事实闭环。** 完整保留源尺寸图中的宽度、承重与有依据的标题；区分新增重复字稿和合法原有标注。测量覆盖不能因模型看见额外真实标注就等价于错误绑定。修正前不放宽硬事实 gate。
3. **局部视野保真需要对照验证。** 当前 QA 只给产品一致性笼统结论，会漏过局部变全景；应在现有观察/判定职责中落实源可见范围，而非新增审美评分或第二套 QA。
4. **重新验证重点图，再扩展整 child。** 当前其余 15 张没有生成，main/scene 的配色一致性、床品覆盖和其他类目未做新实图验收；模板也未验证。不要为了凑齐数量重画本轮失败候选。

这些剩余项没有在冻结生图中偷偷修改。当前结论是“代码修正已落地，首轮受控验证发现未解决的语义与质量问题”，不是“生产整改全部完成”。
