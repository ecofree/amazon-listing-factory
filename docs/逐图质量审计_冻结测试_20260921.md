## 问题明细

### 1. 浴室柜 `scene_04` 的单品数量错误

- 两个变体的 `scene_04` 都把同一柜体并排生成成两台。
- 柜体本身的门、轨道、层板和颜色没有明显断裂，但数量关系改变，容易被理解为“两台装”或套装。
- 根因在场景规划/生成约束没有锁定“单个销售单位”，属于场景语义约束缺失，不是下载或模型路由问题。
- 处理建议：只重做两个变体的 `scene_04`，提示词增加单件约束，并保留现有其他 16 张浴室柜图。

### 2. 浴室镜柜两个 `main` 的镜面被重绘为空白

- `B0GF2357FX/main` 和 `B0DCBRXCMG/main` 的镜面区域均为大面积均匀白色，没有环境反射、边缘高光或真实镜面层次。
- 柜体、门轴、旋钮、侧层板和颜色基本正确，因此问题集中在镜面材质执行。
- 同两个变体的场景图能生成环境反射，说明问题主要发生在 main 的白底/主体编辑契约，而不是产品事实或分类错误。
- 处理建议：只重做两个 `main`，锁定镜面为真实反射材质并保留柜体几何；不要重跑其它角色。

## 已确认没有发现的问题

- 75 张图片全部为 `1600×1600`，文件非空，SHA-256 无重复。
- 床架两个变体的护栏、屋形床头、床板和尺寸图在当前检查中保持一致。
- 人造树两个变体的双株数量、花叶形态、地插和尺寸图保持一致；未发现明显断枝或漂浮尖刺。
- `func*` 和 `size` 图的文字整体清晰，未发现明显乱码、缺字或尺寸图缺失。
- 未发现浴室柜白色变体被错误生成为原木色、床架白色变体被错误生成为原木色的情况。
