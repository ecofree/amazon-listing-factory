## 5. 结论与未完成验证

**提示词去重与精简已完成；复杂图像关系尚未通过。** 尺寸数值、授权文案和独立测量对象保留下来了，但“数值正确、对象名称正确”不保证图中箭头端点正确；“替代位置画虚线”也不保证实体层板数量正确。两套提示都出现这些错误，因此不能把根因简单归为提示长度，也不能用这一次随机输出确定某一句的因果作用。

当前证据支持把后续工作继续放在既有规划与编辑合同中：核对本图唯一实体状态和替代示意的区别、尺寸两个可见端点，以及首图机位是否允许改变。既有测量对象虽写了 rail bottom／slat level，实际模型仍未正确落点，说明仅保留这些名称不足以证明执行可靠。先验证这些关系的具体表达是否有效，再判断需要怎样修改；不继续叠加全品类通用禁令，也不靠无差别重试挑选成功图。

本轮没有重新请求 Gemini 生成规划或运行新审查，不能宣称新的规划说明已在真实规划输出中得到验证。main／scene 的共享措辞变化没有实图复测；没有做全品类、成套图片、发布或 Amazon 接收验收。测试通过只证明当前代码合同及调用行为，本轮失败图片均保留，没有作为成功结果覆盖或隐藏。
