## 结论

3 次请求均成功返回结构化区域；逐图检查后，3 张蒙版均不适合直接作为产品保护区。当前测试路线不能替代精细像素分割。

## 原木床架

- 床尾上横梁与大部分独立竖栏漏选；不能保护完整床架。
- 远侧栏杆与近侧栏杆的孔隙边界错位，部分床品、玩具和背景被纳入保护区。
- 床头屋顶上方墙面被误选，枕头顶部及凹槽内部分摆件也被误选。
- 模型返回的床尾外轮廓存在 2 处严格自交；复杂轮廓的连线关系本身错误。

## 开门壁柜

- 柜体大轮廓和大部分瓶罐、毛巾的归属识别有用，但尚未达到边缘可用精度。
- 左上装饰线及底部轮廓外扩／漏边，同时包含部分白色背景。
- 下层花朵、茎叶和瓶口部分被误选；书本与肥皂周围的排除区边界也不准确。
- 上层瓶罐组合采用粗轮廓，带走可见柜体内壁；返回的外轮廓存在 1 处严格自交。

## 单棵仿真树

- 三个叶球、树干和花盆大致定位到，但输出是简化的粗轮廓。
- 树干之间可见的白色空隙被整片填入保护区，返回孔洞数为 0。
- 叶球边缘存在明显外扩和切边，细小叶片及叶间空隙未被保留。
- 返回轮廓有 1 处严格自交；不能用这张蒙版验证精细主体保护。

## 责任与验证边界

- 三张原图与实际发送图 SHA 完全一致；尺寸分别为 1500×1500、1500×1397、512×1500。不是输入被替换、缩放或非等比拉伸导致。
- 返回明确声明全图归一化坐标；本地按对应宽高转换，未拿检测框填充蒙版，也未自动平滑、扩边或补洞。床尾、柜体、树的原始轮廓分别出现 2、1、1 处严格自交，属于返回几何本身的问题。坐标量化误差不能解释大范围构件漏选与孔洞缺失。
- 三次正常 STOP，输出未达到 16384 token 上限；不能归因为截断。三条 unresolved 都为空，说明返回结果没有主动指出这些可见问题。
- Gemini 基本识别到了要保留的对象／部件和可排除的部分摆件；像素边界、复杂轮廓和孔洞关系没有可靠落实。当前不能仅凭 JSON 有效或 API 成功即接受蒙版。
- 本轮是现有 `gemini-3.7-flash-tiered` 网关、组件多边形输出和现有客户端设置的试验。未测试官方示例中的其他模型、最低思考设置、栅格蒙版输出或局部重分割，因此不泛化为所有 Gemini 路线都不可用。
- 没有像素级人工真值，不报告 IoU、覆盖准确率或可推广的失败率；3 张不合格是本次可复核的视觉结论。

## 接入决定

这三张蒙版不进入生图，不把当前 Gemini 直接描边方式接入生产。Gemini 保持商品语义与规划职责；精细分区需要另行验证合格的能力。不会在本轮自动注册或切换到远程 SAM 服务。
