## 三、通用原则：保留产品，设计产品以外的内容

### 3.1 产品真实性和画面设计分别由现有环节负责

1. **事实层**确定正确子体、销售归属、结构事实、颜色、尺寸及文字授权。矛盾标题、源图营销文字不能覆盖已核实事实；错误变体图片也不能靠提示词改色变成正确变体。
2. **现有视觉规划**选择适合当前角色、展示状态的真实底图，设计房间、摆件、配色、信息布局和成套卖点。
3. **现有提示词编译**把以上信息投射为一次原图编辑指令，先明确可见产品的保留边界，再给可编辑区域的设计目标。
4. **现有生图执行**使用已选底图执行编辑。尺寸线、文案、装饰可以重新布局，产品的构件与连接不能随之重新设计。
5. **已有复核/QA**继续判断事实错误和必要展示。正常遮挡不是零件消失，光照差异不是自动换材质；确有数量、连接、颜色或材质变化则按现有规则处理。

没有新增分区阶段、人工蒙版步骤、第二个规划器、逐单实验或质量门禁。

### 3.2 底图权威要具体，不能只说“参考产品”

- 首张附件是本次实际编辑底图，定义画面中产品的可见外观、结构、连接和视图。
- 辅助附件提供缺少的事实、尺寸或对应细节；不能拼合不同视角，凭空生成一个不存在于底图的整件产品。
- 想展示开门、合门、展开、收纳等不同状态，优先在已有同子体来源中选择真正展示该状态的底图；仅有文字事实不足以授权补画隐藏结构。
- 规划在现有选图/绑定过程中把目标调整为证据能支持的表达。缺少新角度，不应让原本可执行的整件图片一起失败；若特定功能事实本来就不成立，沿用已有针对该任务的处理，不新建全局阻塞。
- 允许产品整体在画布中等比安排、必要的细节裁切、多个真实局部的图文重排；不允许拉伸构件、变更透视后猜造侧面、用新摆件遮住必须展示的功能。
- 第一张附件是待修复候选图的局部修复任务继续沿用其现有语义，不能被误改成重新编辑原始主图。

### 3.3 简洁但完整的合同结构

沿用现有 `[ROLE] / [REFERENCE] / [STYLE] / [TEXT] / [OUTPUT]`，不再在它们外面叠加多层相互重复的保护段。

| 现有段落 | 应承担的内容 |
|---|---|
| ROLE | 直接编辑本图；保留可见产品；本角色要实现什么；哪些非产品内容可变化 |
| REFERENCE | 底图和辅助证据的不同作用；子体身份；必要的结构、功能、测量关系 |
| STYLE | 环境、床品或其它摆设、字体和图文的设计值；不得将配色应用到产品饰面 |
| TEXT | 现有唯一授权文案与测量文字，不把观察描述、目标句或源营销文字变成新增图中文字 |
| OUTPUT | 现有输出规格，不引入额外成图阶段 |

通用语义示例（由现有字段填充，不在代码里另建第二套模板系统）：

> 直接编辑第一张图片。保留图中可见的销售产品及其构件数量、间距、连接、比例、视图、颜色、材质与纹理。按照本角色目标重新设计允许变化的环境、非销售摆设和图文；产品缝隙中可见的环境也同步处理。设计与产品保留冲突时调整设计。辅助图仅补充已核实证据，不授权重构产品或补画隐藏安装面。

main/scene 可以减少重复的受众说明及逐项产品复述；func/size 中必要的对象、关系、尺寸端点和可见证据不能为了缩短提示词而删除。产品数量、尺寸与安全功能仍来自原有事实权威，不从这张床的经验硬编码。

## 四、跨品类推广：通用的是规则，变化的是销售边界

当前代码中 bed_frame、bathroom_cabinet、medicine_cabinet、artificial_tree 均有现成的 `structure_invariants`、`replaceable_staging` 和角色策略。优先复用；不要新增一套重复的品类配置。

| 品类 | 必须保持的产品 | 可设计内容 | 需要处理的特殊关系 |
|---|---|---|---|
| 床架 | 床头、床尾、侧梁、护栏、入口、支腿、真实储物结构及表面 | 非随售床垫、床品、玩具、房间 | 护栏间的床品可换；固定开口不变成活动门；尺寸推荐不变成新增销售规格 |
| 浴室柜 | 柜体、门覆盖范围、把手、铰链、层板、底座及安装件 | 非随售毛巾、洗护用品、花瓶、房间 | 开口和可调层板位置不能实体化成新板；磁吸扣及防倾倒件的安装面与连接不变 |
| 镜柜/药柜 | 实际门面材质、镜框、门数、开向、铰链、内格、安装形式，已有灯具 | 非随售洗护用品、台面、房间；真实镜面内的环境反射 | 只有确认是镜面的区域才按反射处理；换环境可更新倒影，不能把镜面改成柜内空间、增门或增灯；金属/玻璃/镜面不可混判 |
| 仿真树 | 枝干、可见轮廓和叶片分布、颜色材质、销售底座/花盆/地钉及连接 | 背景、家具、周边装饰；已确认非随售的独立装饰盆 | 树叶本身属于产品；地钉不能改成落地支脚；使用场景与安装介质一致，不通过盆景设计隐藏必须展示的支撑结构 |

跨品类时，销售归属以具体子体事实为准，不能仅凭物体名称判断。床垫、花盆、收纳篮在不同商品中可能属于商品或布景。

**镜面是关键例外：** 保护的是镜面材质、轮廓与安装结构，不是强行保留旧房间倒影。透明门板同理，背后可见的非销售物品可换，门板厚度、纹理与边框仍保留。

本轮床架采用项目既有 lifestyle main 策略；其余三个品类仍按各自现有白底 main 策略。不要把成功床图的卧室场景套到所有主图。

办公椅当前 `lifecycle: unsupported`，没有完整启用条件。通用方法在概念上可延伸，但此次不顺便启用该类目，也不把一个新类目接入项目混进本轮保真修订。

## 七、接受标准

- 以用户已接受的本轮视觉效果为基准：看得出同一产品，不能出现明确的部件数量、连接、比例、销售颜色或材质改写；木纹要保持原产品可辨识特征。
- 环境与非销售摆设确实更新，不能靠复制原图获得形式上的保真；图文角色的文字和布局可更新。
- 正常采光、抗锯齿和分辨率造成的差异，不设像素差异阈值、不自动判重绘。正常床品遮挡不新增硬门禁；当前角色必须说明的连接、安装或尺寸关系应能被看清。
- 尺寸、功能、安全结构等明确事实仍按现有准确性要求；本轮样本接受不等于放宽其它已存在的事实要求。
- 未知或局部不可判记录具体位置，不计为确定错误，也不宣传为已经证明；使用现有任务/复核机制处理，不新增等待批准状态。
